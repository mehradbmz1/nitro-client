## Overview & Highlights

Nitro Client delivers optimized throughput, low socket latency, and seamless connectivity through modern networking architecture:

- **Intelligent Anycast Edge Diagnostics**: Accurate real-time latency testing powered by Anycast edge routing.
- **Flexible Performance Profiles**:
  - **Standard Mode**: Ultra-low data consumption with automated idle socket timeouts.
  - **Turbo Mode**: High-throughput multi-channel multiplexing and TCP Fast Open for maximum speed.
  - **Gaming & Resilient Modes**: Low-jitter transport and packet fragmentation for restrictive network environments.
- **Multi-Protocol & Format Compatibility**:
  - Full native support for VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, and WireGuard.
  - Decryption and parsing support for Napsternet (`.npvs`, `.npv`, `.npv4`), Sing-Box, and Clash formats.
- **Dynamic Port Management**: Automatic local port allocation to prevent socket collisions.
- **Secure Local Storage**: Sensitive client configuration parameters encrypted with zero CPU overhead.
- **Modern Desktop & Mobile Experience**: Clean, ergonomic user interface with responsive Dark and Light themes.

## Quick Start

### Windows
1. Download and run `NitroVPN_Setup.exe`.
2. Follow the on-screen prompts to complete installation.
3. Launch **Nitro Client** and import your configuration or subscription link.

### Android
1. Download `NitroVPN_Release.apk`.
2. Open the file on your device and follow the installation prompt.
3. Launch the application and grant the connection permission when prompted.
